# ai-ready-data-tool

أداة سطر أوامر تُجهّز ملفات CSV الخام لمرحلة النمذجة: توحيد أسماء الأعمدة،
معالجة القيم المفقودة، وحذف التكرارات.

> هذا المستودع هو **نقطة البداية** لمسار Git & GitHub، وهو نفسه المشروع الذي
> يكتمل في المشروع التطبيقي الشامل لاحقاً في البرنامج. لا شيء هنا يُرمى.

## المتطلبات

- Python 3.9 فأحدث — **بلا أي مكتبة خارجية للتشغيل**
- `pytest` لتشغيل الاختبارات فقط

## التشغيل

```bash
python clean.py                       # يقرأ الإعدادات من config.yaml
python clean.py --strategy median     # يتجاوز الإعدادات لمرة واحدة
python -m pytest -q                   # الاختبارات
```

## بنية المشروع

```
ai-ready-data-tool/
  clean.py            ← واجهة توافق وتشغيل قديمة
  enrich.py           ← واجهة توافق وتشغيل قديمة
  src/
    fileManager/io.py ← قراءة الملفات وكتابتها فقط
    roles/logic.py    ← الحسابات وقواعد العمل فقط
    media/cli.py      ← معالجة الوسائط والطباعة فقط
  config.yaml         ← الإعدادات (سطر missing_strategy مهم في المختبرات)
  requirements.txt
  data/raw/           ← بيانات خام — لا تُرفع إلى Git
  output/             ← ناتج التشغيل — لا يُرفع إلى Git
  tests/test_clean.py
  lab-setup.py        ← يهيّئ حالة المستودع لكل مختبر (للمدرب)
```

## الإعدادات

| المفتاح | القيم | المعنى |
|---|---|---|
| `input` | مسار | ملف CSV الخام |
| `output` | مسار | مكان الملف النظيف |
| `missing_strategy` | `mean` · `median` · `drop` | معالجة الخلايا الفارغة في الأعمدة الرقمية |
| `drop_duplicates` | `true` · `false` | حذف الصفوف المكررة |

## اليوم السادس — الكود النظيف

توجد الآن طبقات واضحة؛ يضيف منطق الإثراء أعمدة مشتقّة (الإجمالي، الخصم، الضريبة،
رمز المنطقة، علامة الشذوذ، علامة القيمة العالية) إلى الملف النظيف تمهيداً للنمذجة.

الملف **يعمل**، ومخرجاته **صحيحة**، والاختبارات الخمسة عشر **كلها ناجحة**. وهذا بالضبط ما يجعله
مادة اليوم: الكود السيّئ ليس كوداً مكسوراً.

```bash
python clean.py            # ينظّف الملف الخام
python enrich.py           # يضيف الأعمدة المشتقّة
pytest tests/ -q           # 15 passed
python metrics.py enrich.py solutions/enrich_clean.py
```

### ملفات جديدة

| الملف | الدور |
|---|---|
| `src/fileManager/io.py` | قراءة ملفات CSV وكتابتها وقراءة الإعدادات |
| `src/roles/logic.py` | قواعد التنظيف والإثراء والحسابات دون إدخال/إخراج |
| `src/media/cli.py` | معاملات سطر الأوامر والرسائل والطباعة |
| `clean.py` و`enrich.py` | واجهات توافق تحافظ على التشغيل والاستيراد القديمين |
| `tests/test_enrich.py` | تسعة اختبارات تثبيت سلوك — شبكة الأمان |
| `metrics.py` | مقياس نظافة بالمكتبة القياسية وحدها، بلا أي تثبيت |
| `pyproject.toml` | إعدادات `ruff` جاهزة — `ruff check .` |
| `solutions/enrich_clean.py` | نسخة المدرّب المرجعية — **لا تفتحها قبل انتهاء المختبرات** |

### القاعدة

قبل أي تغيير وبعده:

```bash
pytest tests/ -q                                        # يجب أن تنجح 15 دائماً
python enrich.py --output output/now.csv
diff output/baseline.csv output/now.csv                 # يجب أن يكون فارغاً
```

الفرق الفارغ هو دليلك — لا شعورك، ولا أن الكود «يبدو أنظف».
