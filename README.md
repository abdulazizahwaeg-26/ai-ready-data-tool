# ai-ready-data-tool

أداة سطر أوامر تُجهّز ملفات CSV الخام لمرحلة النمذجة: توحيد أسماء الأعمدة،
معالجة القيم المفقودة، وحذف التكرارات.

> هذا المستودع هو **نقطة البداية** لمسار Git & GitHub، وهو نفسه المشروع الذي
> يكتمل في المشروع التطبيقي الشامل لاحقاً في البرنامج. لا شيء هنا يُرمى.

## المتطلبات

- Python 3.9 فأحدث — **بلا أي مكتبة خارجية للتشغيل**
- `pytest` لتشغيل الاختبارات فقط

## التشغيل

```bash
python clean.py                       # يقرأ الإعدادات من config.yaml
python clean.py --strategy median     # يتجاوز الإعدادات لمرة واحدة
python -m pytest -q                   # الاختبارات
```

## بنية المشروع

```
ai-ready-data-tool/
  clean.py            ← منطق الأداة
  config.yaml         ← الإعدادات (سطر missing_strategy مهم في المختبرات)
  requirements.txt
  data/raw/           ← بيانات خام — لا تُرفع إلى Git
  output/             ← ناتج التشغيل — لا يُرفع إلى Git
  tests/test_clean.py
  lab-setup.py        ← يهيّئ حالة المستودع لكل مختبر (للمدرب)
```

## الإعدادات

| المفتاح | القيم | المعنى |
|---|---|---|
| `input` | مسار | ملف CSV الخام |
| `output` | مسار | مكان الملف النظيف |
| `missing_strategy` | `mean` · `median` · `drop` | معالجة الخلايا الفارغة في الأعمدة الرقمية |
| `drop_duplicates` | `true` · `false` | حذف الصفوف المكررة |
